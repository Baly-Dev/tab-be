# Notifications

Scaffolding vuoto. Inbox in-app e push Flutter verranno ridisegnati.

## A cosa servirà

Eventi prodotto (connessioni, onboarding, ecc.) con persistenza e/o canali push.

## Struttura

- `api/v1/` — route HTTP
- `models/` — SQLAlchemy
- `schemas/` — Pydantic
- `services/` — scrittura eventi e adapter canali
- `errors/` — errori HTTP e dominio
