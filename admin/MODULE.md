# Admin

Scaffolding vuoto. Console operativa e analitica verranno ridisegnate (metriche intranet, export, audit).

## A cosa servirà

Endpoint staff sotto `/api/v1/admin` per operatività e reportistica consumer.

## Struttura

- `api/v1/` — route HTTP
- `models/` — SQLAlchemy
- `schemas/` — Pydantic
- `services/` — logica di dominio
- `errors/` — errori HTTP e dominio
